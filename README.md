# Toledo Segurança — protótipo institucional

Projeto inicial em React + TypeScript + Vite, criado para continuidade no MonkeyCode.

## Direção visual
- Preto e branco como base.
- Dourado como cor de destaque.
- Sem fotos de equipe, operações, clientes ou instalações.
- Logotipo e símbolo da caveira fornecidos como assets.
- Clientes apresentados por nomes no protótipo; logos reais podem ser adicionados depois.

## Conteúdo
O protótipo inclui:
- Hero institucional
- Quem somos / A Toledo (posicionamento, missão, história, valores)
- Serviços (10 frentes confirmadas)
- Área de atuação: Jundiaí e região
- Diferenciais
- Empresas atendidas (nomes autorizados)
- Como funciona
- Trabalhe conosco
- Formulário de candidatura com upload de currículo (interface/protótipo)
- FAQ
- Solicite orçamento (preenche os dados e abre o WhatsApp)
- Contato completo (WhatsApp, e-mail, Instagram, endereço e horário)
- Footer institucional/legal
- Favicon da caveira

## Importante
O formulário de candidatura ainda não possui backend de envio. Na etapa de produção, conectar o formulário a um serviço/backend de envio de e-mail e revisar a Política de Privacidade/LGPD.

O bloco "Solicite orçamento" não armazena dados: apenas monta a mensagem e direciona para o WhatsApp.

A empresa não realiza segurança armada. A nomenclatura dos serviços de segurança deve ser validada juridicamente antes da publicação definitiva.

## Comandos
npm install
